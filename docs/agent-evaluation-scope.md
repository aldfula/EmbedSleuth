# 실제 에이전트 통합 검증 1턴의 범위

상태: 2026-11-26 사용자가 설명한 실제 에이전트 통합 검증을 진행하도록 승인했다(“그래 그거 해보자”). **승인된 실제 모델 1턴을 실행하고 사람의 증거·보고 의미 검토까지 통과했다.** 이전에 승인한 가짜 장치 평가 3턴은 모두 사용했으며 이번 승인은 별도다.

## 실행 목적과 데이터

- 목적지: 기존 Codex 로그인에 설정된 OpenAI 기본 모델 gpt-6.1-sol. provider·모델이 다르거나 base URL 재지정이 있으면 모델 턴 전에 중단한다. 새 API 키나 제품용 LLM 클라이언트는 만들지 않는다.
- 횟수: 최대 1개 실제 모델 턴, 180초 제한. 한 턴에는 도구 선택에 따른 여러 모델 요청이 있을 수 있다. 실패·중단 후 모델이나 하드웨어를 자동 재시도하지 않는다.
- 입력: 공개 저장소의 실제 diagnose-mpu6050 스킬·두 참조 문서·아홉 MCP 도구 스키마, 아래 자연어 요청, 일반 Codex 호스트 지시·문맥. 실제 저장소의 신뢰된 세 훅과 생산 MCP를 사용한다.
- 요청: `$diagnose-mpu6050로 등록 대상 raspberrypi-local-aldfula의 Raspberry Pi와 MPU6050 연결 환경을 센서 통신 없이 조사하고, 실제 증거와 미확인 사항을 보고해 줘.` 명시 스킬 호출 1표본이며 자동 선택 정확도의 일반 평가로 확대하지 않는다.
- 모델에 전달되는 실제 값: 등록 대상 ID(이름에 계정 식별 문자열이 포함됨), 새 실행·증거 ID, Pi 모델·OS·커널·Python 버전, 부트 ID, 공개 호스트 키 지문, I2C 버스·어댑터·권한·전송 지원·드라이버 점유·관련 설정 요약, 자원·cgroup 관측, 규칙·보고서.
- 제외: 실제 SSH 호스트명/IP·접속 계정 필드·키 파일 경로·개인키·비밀번호·운영 등록 파일·이전 실물 보고서·기존 대화. 논리 target_id의 식별 문자열은 위에 명시한 예외이며 접속 정보로 숨겨 취급하지 않는다. 인증 파일은 직접 읽거나 복사하지 않는다.

## 읽기와 호스트 제한

[실행기](../scripts/run_agent_acceptance.py)는 기존 대상·등록·공유 저장소를 유지한다. 새 ephemeral 호스트 문맥에 실제 스킬 입력을 붙이고 두 공개 참조를 제공한다. 다른 MCP 서버·앱·브라우저·셸·이미지·하위 에이전트 도구는 해당 실행에서만 비활성화하고 read-only·networkAccess=false sandbox를 사용한다. 활성 MCP가 EmbedSleuth 한 개가 아니면 모델 턴 전에 중단한다. 호스트가 목록에 남기는 다른 서버는 runtimeStatus=disabled이고 tools·resources·resourceTemplates가 모두 빈 경우만 허용한다. 설치 플러그인은 이번 호출에서만 비활성화한다. 설치된 CLI 0.172.0에는 최신 문서의 세밀한 읽기 경로 제한이 없어 그 기능을 주장하지 않는다. 파일을 열어 스킬을 찾을 필요가 없도록 본문·참조를 제공하고, 설정·키·기존 증거 접근을 지시에서 금지한다. 영구 설정은 바꾸지 않는다. MCP 서버 자체는 기존 운영자 관리 연결로 실행한다.

- 새로운 passive 실행 한 건의 inspect_target와 inspect_i2c_environment를 순서대로 각각 1회만 승인 응답한다. 사전에 있던 run_id·다른 대상·다른 서버·다른 실행·잘못된 모드·중복 호출은 허용하지 않는다.
- 센서 직접 읽기·0x69·주소 스캔·SSH 명령·sudo·설치·설정 변경·재부팅·격리 해제는 허용하지 않는다.
- 사용자의 기존 승인 정책·MCP 영구 허용·훅 신뢰를 변경하지 않는다. 세 훅이 이미 trusted가 아니면 턴 전에 중단한다. 읽기 승인은 위 두 요청의 일회성 응답이며 그 외 승인·질문 요청은 거부한다.
- 원격 오류가 나면 보고서/취소만 처리한다. 완료가 불명확하면 기존 코어가 격리하며, 이전 취소 건의 복구 승인을 새 오류에 재사용하지 않는다.

## 판정과 기록

명시 스킬 로드, 실제 모델의 도구 선택, 프로젝트 PreToolUse·PostToolUse·Stop 완료 이벤트와 검증 영수증, 기존 RunStore의 닫힌 감사·pending=null·partial 보고서, 최종 한국어 설명을 대조한다. 센서 전송이 없으므로 partial은 정상이며 complete나 센서 정상 보장을 요구하지 않는다. 실제 하드웨어 진단 1표본이며 장애·일반 라우팅·모든 보고 품질의 보장은 아니다.

이벤트·결과·실행/증거·훅 문맥은 Git에서 제외한 .embedsleuth-local에 소유자 전용으로 보존한다. 외부 모델은 현재 Codex 계정의 사용 한도를 소비할 수 있다. 기존 3턴 승인을 재사용하지 않으며 이 문서 자체는 전송 승인이 아니다.

실행기 오프라인 시험은 모델·Pi·인증 파일 없이 수행했다. [공식 App Server 스킬·훅 이벤트 계약](https://learn.chatgpt.com/docs/app-server), [공식 훅 문서](https://learn.chatgpt.com/docs/hooks)를 참조했다.
